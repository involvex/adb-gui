# Plan: Add `adb-gui` CLI Bin Entry

## Goal

Add a `bin` entry to `package.json` so `bun link` lets the user run `adb-gui` from any directory and launch the Electron app.

## Design Decisions

- **Default mode**: Dev (`bun run dev`) — useful during active development, no build step required
- **Prod mode**: `adb-gui --prod` runs `electron .` — requires prior `bun run build`
- **Package root detection**: resolve from `import.meta.path` / `import.meta.dir`, follow `process.cwd()` but spawn from package root
- **Windows**: use `shell: true` so PATH resolution works for `bun` and `electron`

## Files to Change

### 1. Create `src/cli.ts`

- Parse `--prod` / `-p` flag
- Determine package root from `import.meta.path` resolution
- Spawn child process with `cwd: PACKAGE_ROOT`
- Forward exit code, handle `EACCES` gracefully

### 2. Update `package.json`

- Add `"bin": { "adb-gui": "./src/cli.ts" }`

## Validation

- `bun link` then `adb-gui` from another directory opens dev window
- `adb-gui --prod` works after `bun run build`
- `bun run typecheck` passes
